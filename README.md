# moeinbagheri.com

Personal site of Moein Bagheri: my story told in sound, from music in Yazd to machine learning for speech, with my projects, a piano-roll map of my courses, and my CV.

Static HTML, CSS and JavaScript (Three.js, GSAP and Lenis, kept in `vendor/`), served with GitHub Pages. Everything that listens runs in the browser: the microphone is analysed on your device, and no audio is recorded or sent.
